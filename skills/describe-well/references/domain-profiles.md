## domain profiles

these are starter domain profiles. `--domain` can point to one of them or act as freeform guidance when no preset exists.

## vc_pitch

- default axes: domain fluency 6, attention budget 3, epistemic stance 7, action orientation 9
- required terms:
  - market
  - traction
  - runway
  - burn rate
- forbidden terms:
  - hopefully
  - maybe
  - revolutionary
  - game-changing
- precision ceilings:
  - numbers: no fake precision beyond 2 significant figures
  - time: default to month or quarter unless exact dates matter materially
  - claims: every strong claim should tie to traction, distribution, unit economics, or team evidence
- never do this:
  - write aspirational hype with no operating facts
  - use adjectives where a metric or hard comparison would fit
  - bury the business constraint behind product poetry

## technical_docs

- default axes: domain fluency 8, attention budget 5, epistemic stance 8, action orientation 8
- required terms:
  - interface
  - constraint
  - failure mode
- forbidden terms:
  - intuitive
  - simply
  - obviously
- precision ceilings:
  - jargon: allowed, but only if terms are used consistently
  - time: prefer exact versions, endpoints, or sequences when behavior depends on them
  - evidence: claims about behavior should name the condition or limit
- never do this:
  - hide prerequisites
  - imply guarantees where only best-effort behavior exists
  - substitute marketing language for operational detail

## blog_post

- default axes: domain fluency 3, attention budget 5, epistemic stance 5, action orientation 4
- required terms:
  - concrete example
- forbidden terms:
  - leverage
  - paradigm
  - robust
- precision ceilings:
  - jargon: define or replace specialist language unless it is already mainstream
  - density: avoid stacking more than one new concept per sentence unless tightly coupled
  - evidence: mechanism or example is usually enough unless the claim is unusually strong
- never do this:
  - confuse accessibility with vagueness
  - pad the piece with empty intensity words
  - explain every edge case before the main idea is clear
