Articulate

the skill that makes every other skill better
1

Install Claude Code

if you haven't already:

npm install -g @anthropic-ai/claude-code
2

Clone the repo

git clone https://github.com/shenal-maker/ultimate-describer.git
cd ultimate-describer
git checkout skills
3

Copy skills to your project

copy the .claude/skills/ directory into your own project:

# from inside ultimate-describer/
cp -r .claude/skills/articulate /path/to/your/project/.claude/skills/
4

Activate

open Claude Code in your project and run:

/articulate on

it'll quiz you on your preferences, then everything you write gets sharper.
